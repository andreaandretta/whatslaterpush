3 · Service worker (next-pwa)

Via libreria zero-config (consigliato, no nuove dipendenze runtime — solo dev):

npm i -D @ducanh2912/next-pwa

// next.config.js
const withPWA = require('@ducanh2912/next-pwa').default({
  dest: 'public',
  disable: process.env.NODE_ENV === 'development',
  cacheOnFrontEndNav: true,
  fallbacks: { document: '/offline' },
});
module.exports = withPWA({ /* existing config */ });

Crea app/offline/page.tsx — schermata dark "Sei offline · i messaggi programmati partono comunque dal server".

4 · Splash screen

  • Android: generato auto da background_color (#111B21) + icona. Niente da fare.
  • iOS: serve apple-touch-startup-image per ogni size, oppure splash semplice. Per il lancio basta theme-color + icona; gli splash iOS si aggiungono dopo.
  • Se vuoi lo splash brandizzato (verde scuro + icona pop) → component React mostrato per 0.8s al primo mount mentre l'app idrata.

5 · Install banner (component nuovo)

app/components/InstallPrompt.tsx — montato in dashboard:

  • Intercetta evento beforeinstallprompt, preventDefault(), salva l'evento.
  • Mostra il banner slide-up solo dopo il 1° messaggio programmato (flag localStorage wl_first_msg_done) e se non già dismesso (wl_install_dismissed).
  • Tap "Aggiungi" → deferredPrompt.prompt(). "Più tardi" → set dismissed.
  • iOS (no beforeinstallprompt): se navigator.standalone === false e Safari, mostra istruzione "Condividi → Aggiungi a Home".
  • Stile: card bg-[#1F2C33], icona app a sx, "Aggiungi alla schermata Home / Apri WhatsLater con un tap", bottone verde + "Più tardi" grigio. (Vedi mockup pwa-concept.html.)

Checklist test PWA

  • Lighthouse PWA audit → installabile (manifest + SW + icone ok)
  • Android Chrome: "Aggiungi a schermata Home" appare, icona maskable ritagliata a cerchio corretta (no bordi mozzati)
  • iOS Safari: Condividi → "Aggiungi a Home" → icona 180px nitida, status bar coerente col theme
  • Offline: apri app senza rete → shell dashboard carica, pagina /offline come fallback
  • start_url /dashboard apre direttamente loggati (non la landing)
  • theme-color #075E54 colora la status bar in standalone
